# Bug catalogue

45 failure modes a reconciliation engine meets sooner or later. Each one has a fixed ID, a protection built into
the design, and tests named after the ID, such as `B21_concurrent_duplicate_upload`.

This file is checked on every build (`BugCatalogueTest`): every ID needs at least one test, and every test class
with tests for an ID must be linked in its row. A new bug gets the next ID (B46, …) and a failing test first.
